# INSIGHT RP

RP education, sharing, discussion, and AI practice platform for Totalins.

## Goal

Build a web app where users can sign up, log in, upload RP materials, share field-tested scripts, discuss better counseling flows, and practice with AI.

## Planned Stack

- Current prototype: static HTML, CSS, and JavaScript
- Future web app: Next.js
- Auth and database: Supabase
- Deployment: Vercel
- Static hosting option: GitHub Pages
- Source control: GitHub

## Brand Direction

INSIGHT RP stands for a premium roleplay intelligence workspace for (주)글로벌금융판매 토탈인스총괄.
